# Traffic monitoring videos

Place local MP4 files in this directory with these exact names:

- `traffic-feed-1.mp4`
- `traffic-feed-2.mp4`
- `traffic-feed-3.mp4`
- `traffic-feed-4.mp4`
- `traffic-feed-5.mp4`
- `traffic-feed-6.mp4`
- `traffic-feed-7.mp4`
- `traffic-feed-8.mp4`

Each file maps to the corresponding corridor card in Traffic Monitoring. MP4/H.264 is recommended for Chromium and Docker browser compatibility. While a file is absent, the dashboard displays its traffic poster instead of failing.
